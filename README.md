# PRODUCT INSIGHTS THROUGH WEB SCRAPING, ANALYSIS, AND DATABASE INTEGRATION

## Project Overview

This project demonstrates an end-to-end Python workflow for collecting product data from a public website, cleaning and processing the data, performing analysis, creating visualizations, and integrating the processed data with a SQL Server database.

The project covers:

- Web scraping
- Data cleaning and processing
- Python programming concepts
- NumPy and Pandas analysis
- Data visualization
- Object-oriented programming
- File handling
- SQL Server database integration

---

## Source Website

The project uses the following public website for web scraping:

https://books.toscrape.com/

The scraper collects product information and continues through pagination until 100 products are collected.

## Project Files

### Python Source Files

` scraper.py `
- Fetches web pages using Requests.
- Parses HTML using BeautifulSoup.
- Handles pagination.
- Collects at least 100 products.
- Saves the raw data to `raw_products.csv`.

` processor.py `
- Reads the raw CSV file.
- Converts numeric columns.
- Handles missing values.
- Removes duplicate products.
- Cleans product IDs and text fields.
- Performs string, list, tuple, and dictionary operations.
- Creates calculated columns.
- Performs statistical and NumPy analysis.
- Saves the processed data to `clean_products.csv`.

` analyzer.py `
- Reads `clean_products.csv`.
- Performs data analysis.
- Creates the required visualizations.
- Saves the charts inside the `charts` folder.
- Creates `analysis_summary.txt`.

` db_handler.py `
- Connects to SQL Server using pyodbc.
- Creates or uses the `ProductDB` database.
- Creates or uses the `Products` table.
- Loads cleaned product records.
- Executes SQL queries.
- Displays product records, top products by price, and category counts.

` main.py `
- Runs the complete project workflow in sequence.
